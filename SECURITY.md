# Sicherheit

Das Sitzungsgeheimnis liegt im Schlüsselbund des Betriebssystems. Nicht geheimer Zustand liegt unter `%APPDATA%\openover-desktop`.

Eine Sicherheitslücke bitte nicht öffentlich im Issue-Tracker beschreiben. Öffnet ein [Security Advisory](https://github.com/SylvanoP/pushover-desktop/security/advisories/new) für dieses Repository.
